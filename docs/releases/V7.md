# piBrick AOSP 17 V7 — sortie audio interne

La V7 est une release cumulative destinée au piBrick Pocket CM5 avec l'image
KonstaKANG AOSP 17 du 2 juillet 2026.

## Fonctions validées

- AMOLED 1080×1240 à 90 Hz ;
- HDMI-1 et HDMI-2 ;
- luminosité AMOLED de 0 à 100 % et boutons en 20 pas ;
- tactile Hynitron CST3530, 5 points ;
- autorotation MMA8451Q dans les quatre orientations ;
- sortie audio sur les haut-parleurs internes C-Media ;
- route Android persistante `persist.vendor.audio.device=dac` ;
- carte C-Media interne exclue du classement « casque USB externe ».

## Installation

Après extraction de l'archive et passage du piBrick en mode `rpiboot` :

```bash
chmod +x install.sh
./install.sh
```

Cette commande unique contrôle le paquet, détecte l'état déjà installé, crée
les sauvegardes et applique uniquement les étapes nécessaires.

## Limites connues

- **Microphone : non validé.** Le niveau reste faible et la stabilité n'est pas
  encore concluante.
- **Batterie : non validée.** Le niveau affiché est perturbé par le branchement
  ou le retrait d'une alimentation et ne représente pas toujours l'état réel.
- Le `vendor.img` expérimental V8.1.3 n'est pas inclus : il empêchait Android
  de démarrer et a été rejeté.
